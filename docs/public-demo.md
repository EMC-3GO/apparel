# 授業用の公開デモ

Vercelのルート `/` は、Googleログインやアプリ独自のパスワードなしで直接ダッシュボードを表示します。
初期データは空です。商品・収入・支出を自分で登録できます。既存のサンプルや入力を消したい場合は画面上部の「データをリセット」を使います。削除前の確認とキャンセルがあり、リセット後も再読み込みでサンプルは復活しません。Googleスプレッドシート・実際の注文情報には接続しません。

各閲覧者の変更は、そのブラウザのlocalStorageに保存します。他の人・他のブラウザとは共有しません。同じブラウザの同じサイトを使う人は保存内容を見られます。授業では実際の氏名・住所を入力しないでください。
デモの収支・受注・アドバイス条件は `anffel-classroom:` の保存キーを使い、旧ローカル版の個人データから分離します。旧版は `/legacy/` です。

## 公開に反映する

1. 変更をVercelが接続するGitHubリポジトリの本番ブランチへ反映します。
2. Vercelで対象プロジェクトを開き、最新の本番デプロイの完了を確認します。Build Commandは `npm run build`、Output Directoryは `dist` です。
3. Vercelの Settings → Deployment Protection で、授業に共有する本番URLにログイン要求がかからない設定を確認します。
4. GoogleにもVercelにもログインしていないシークレットウィンドウで、本番URLを開き、直接ダッシュボードが表示されることを確認します。
5. この本番URLを共有します。`script.google.com/.../exec` は授業デモの共有先ではありません。

コードの変更・ビルド完了は、本番デプロイの完了を意味しません。

## Google版

Googleスプレッドシート保存版は本人専用のままです。アプリ独自のパスワード・ロック・解除コードは廃止しましたが、Google本人確認は残します。公開デモとしてこのURLを使う必要はありません。
既存Google版も更新する場合はCode.gsを置き換え、既存デプロイの新バージョンを公開します。旧パスワード等のスクリプトプロパティは使いません。既存の商品・記録・注文は初期化しません。
