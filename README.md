# atelier — アパレル事業の収支管理プロトタイプ

企画概要書に基づく日本語のブラウザアプリです。React / Vite を使用しています。

## 起動

Node.js 24 / npm 11 で検証済み。

```sh
cd /workspace/apparel
npm ci --cache /tmp/apparel-npm-cache
npm run dev -- --port 5173
```

## 検証

```sh
npm test
npm run build
# 開発サーバー起動中に実行。/usr/bin/chromium を使用します。
node tests/browser.mjs
```

## 試せること

- 累計・月別の収支、収入・支出の推移、利益の内訳
- 商品登録・編集、在庫販売と受注生産、費用の確定・取消
- 数量 × 販売単価 − 値引きによる売上計算
- 収入・支出・返品の登録、修正、削除と全画面への即時反映
- 商品別の集計、共通費用の一覧、記録検索、CSV出力
- モバイルのメニューと入力、ブラウザ内への自動保存

## 試作時の集計ルール・制限

2026年5〜10月の架空データを初期表示します。保存先は localStorage の `atelier-ledger-v1` です。実口座・外部サービスとは接続していません。ログイン、サーバー保存、端末間同期、正式な会計処理は未実装です。ブラウザの保存領域を削除するとデータが消えます。CSVはエクスポート専用です。

製造費とタグ・資材を製造原価に、その他支出を経費として、記録日付で集計します。共通費用は商品に配分しません。受取送料はその他収入として利益へ加算します。原価の在庫配分・税務上の期間帰属は扱いません。受注生産の費用が未確定の場合、その商品とブランドの売上総利益・最終利益は未確定と表示します（ブランドの収支差額は登録済み記録の実数）。

売上の単価は登録時に保存し、商品価格を変更しても過去の売上は変わりません。返品は独立したマイナス売上で、元の売上との自動照合や超過返品の制限はありません。元取引の単価・値引き・数量を確認してください。送料・手数料は項目ごとに追加登録します。

推移グラフは直近12か月までを表示します。累計金額には全期間の記録を含みます。
